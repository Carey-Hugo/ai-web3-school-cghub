## 一、拆解项目：AIGC.art（创作者经济 × Web3 探索）

> 说明：AIGC.art 是国内较早尝试将 AI 生成内容与区块链结合的平台，属于国内创作者经济 × Web3 的先行案例。

### 1.1 基本信息

| 维度 | 信息 |
|------|------|
| **类型** | AI 生成艺术平台 + NFT 铸造 |
| **成立时间** | 2023 年 |
| **核心功能** | AI 生成图片 → 一键铸造 NFT → 交易 |
| **技术栈** | Ethereum NFT（ERC-721）+ AI 生图模型 |
| **目标用户** | 数字艺术爱好者、创作者、收藏者 |

### 1.2 商业模式

```
收入来源：
  - NFT 铸造手续费（平台抽成）
  - 二次交易版税（每次转售抽取 5-10%）
  - AI 算力消耗（用户付费生图）

核心价值链：
  AI 生图（用户） → 铸造 NFT（平台） → 发行/交易（NFT 市场）
                                            ↓
                                      版税回流创作者
```

### 1.3 AI×Web3 融合方式

| 维度 | 实现方式 | 评价 |
|------|---------|------|
| **AI 融合** | AI 生图 → NFT | 浅层融合，AI 只是工具 |
| **链上确权** | 铸造为 ERC-721 | 有，NFT = 链上所有权 |
| **价值分配** | 二次交易版税 | 有，但依赖平台中心化执行 |
| **去中心化** | 依赖平台服务器 | 低，平台关闭即消失 |

### 1.4 值得 CGHub 借鉴的点

```
✅ 借鉴：
  - AI 生图 + NFT 铸造的最小可行路径
  - 版税机制（创作者持续获得二次收益）

❌ 问题/局限：
  - 平台中心化：创作者没有真正控制权
  - AI 只是工具：没有 AI Agent 参与创作/协作
  - 无贡献记录：谁贡献了什么，没有链上追踪
  - 无智能合约分配：版税由平台代发，非自动执行
```

### 1.5 对 CGHub 的启发

```
AIGC.art 解决了"AI 作品上链"的问题，
但没有解决"创客协作中贡献如何记录和分配"的问题。

CGHub 的机会：
  在 AIGC.art 的基础上，增加：
    1. AI Agent 记录创作过程（不只是结果）
    2. 多方协作的贡献权重系统
    3. 智能合约自动分配（不依赖平台）
```

## 二、拆解项目：Gitcoin Passport（贡献者身份 × 声誉系统）

> 说明：Gitcoin Passport 是 Gitcoin 的链上身份认证系统，通过记录用户在 Web3 中的各种" stamps"（印章）来构建声誉分数，为 Gitcoin Grants 的二次融资提供身份验证基础。

### 2.1 基本信息

| 维度 | 信息 |
|------|------|
| **类型** | 去中心化身份认证 + 声誉系统 |
| **成立时间** | 2022 年 |
| **核心功能** | 收集用户在 Web3 中的"印章" → 生成声誉分数 |
| **支持的印章** | GitHub、Twitter、Discord、Lens、GTC 质押等 30+ |
| **应用场景** | Gitcoin Grants 二次融资身份验证、NFT 空投资格 |

### 2.2 机制设计

```
┌─────────────────────────────────────────────────────────────┐
│                   Gitcoin Passport 工作流程                  │
│                                                             │
│  用户端：                                                   │
│    1. 连接钱包                                             │
│    2. 授权各种 Web2/Web3 账号（GitHub、Twitter 等）         │
│    3. 获得对应的 Stamps（印章）                             │
│    4. Passport 计算综合声誉分数                             │
│                                                             │
│  验证端：                                                   │
│    1. 项目方设定最低声誉分数门槛                            │
│    2. 只有达到门槛的钱包地址才能参与                        │
│    3. 防止女巫攻击（Sybil Resistance）                      │
│                                                             │
│  链上：                                                     │
│    - 声誉数据存储在 Ceramic Network（去中心化存储）          │
│    - 签名验证在链上进行                                     │
│    - 不依赖平台服务器                                       │
└─────────────────────────────────────────────────────────────┘
```

### 2.3 AI×Web3 融合方式

| 维度 | 实现方式 | 评价 |
|------|---------|------|
| **AI 融合** | 较弱，核心是身份认证 | 待探索：AI 可辅助声誉评估 |
| **链上确权** | 声誉数据存 Ceramic，签名验证上链 | 有，去中心化程度较高 |
| **价值分配** | 间接（ Grants 分配参考声誉分数） | 有，但非直接分配协议 |
| **防女巫** | 身份多样性验证 | 有效但不完美 |

### 2.4 值得 CGHub 借鉴的点

```
✅ 借鉴：
  1. 声誉系统思路：CGHub 可以做"创客声誉分数"
      - 作品完成数
      - 协作参与度
      - 社区贡献
      - 智能合约执行记录

  2. 多维度身份认证：CGHub 不依赖单一维度
      - GitHub 贡献数据
      - Lens 社交图谱
      - 智能合约交互记录
      - AI Agent 协作评分

  3. 防女巫机制：CGHub 可以用类似思路
      防止刷贡献、刷声誉

❌ 问题/局限：
  - 声誉是静态的：没有实时更新和动态权重
  - 无 AI 参与：声誉计算是规则驱动的，非 AI 驱动
  - 无贡献分配：只验证身份，不参与分配逻辑
```

### 2.5 对 CGHub 的启发

```
Gitcoin Passport 证明了"链上声誉"是可行的。
CGHub 可以做"创客版 Passport"，但要更进一步：

Gitcoin Passport: 你是谁（身份验证）
CGHub Passport:  你做了什么 + 能做什么 + 价值多少

关键差异：
  - CGHub 的声誉是动态的（基于 AI 贡献追踪）
  - CGHub 的声誉直接连接价值分配（智能合约）
  - CGHub 的 AI Agent 不只记录，还评估和执行
```

## 三、综合结论：两个项目对 CGHub 的启发

### 3.1 行业现状总结

```
AI×Web3 当前发展阶段：
  阶段 1（已完成）：AI 生成内容上链（NFT）
  阶段 2（进行中）：链上身份与声誉系统
  阶段 3（待探索）：AI Agent 参与贡献追踪与价值分配

当前市场空白：
  没有一个平台做到：
    AI 追踪贡献 → 链上确权 → 智能合约自动分配
  这个闭环就是 CGHub 的机会。
```

### 3.2 CGHub 的差异化定位

```
                    AIGC.art          Gitcoin Passport         CGHub
                    （内容上链）       （身份认证）          （价值操作系统）

AI 参与深度          生图工具          无 AI                 全程 AI 追踪
贡献记录             无                弱（静态声誉）        强（动态追踪）
价值分配             平台代发          间接（参考声誉）      智能合约自动
去中心化程度         低                中                   高
创客协作支持         无                无                   有
```

### 3.3 CGHub 的核心技术参考

| 参考项目 | 借鉴什么 | 如何超越 |
|---------|---------|---------|
| AIGC.art | AI→NFT 最小路径 | 加入贡献记录层 |
| Gitcoin Passport | 声誉系统设计 | 动态声誉 + 价值分配闭环 |
| Safe | 多签金库 | CGHub 金库 + 创客贡献追踪 |
| Lens Protocol | 去中心化身份 | CGHub 创客主页 |

## 四、核心结论

**W1-08 学习结论：**

1. **AIGC.art 证明**：AI 内容上链是可行的，但缺乏协作和贡献追踪
2. **Gitcoin Passport 证明**：链上声誉是有效的防女巫机制，但静态且无价值分配
3. **CGHub 的机会**：在两者基础上，做"AI 全程参与 + 贡献动态追踪 + 智能合约自动分配"的闭环
4. **技术参考**：整合 Safe（资产安全）+ Passport（声誉系统）+ 自主研发的贡献追踪协议
