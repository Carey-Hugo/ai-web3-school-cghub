## 学习内容

### Task 1 · LLM 基础

**核心理解：**
- LLM = 文本生成器，根据上下文预测 token
- 能做：总结、写代码、生成计划、抽取结构化信息、多步推理、工具调用
- 不能做：替代数据库、承担事实校验、单独控制权限、单独执行真实动作

**四个关键概念：**
1. Token — 模型处理文本的基本单位，影响上下文容量和成本
2. Embedding — 把文本映射成向量，衡量语义是否接近
3. Transformer — LLM 核心架构，依赖 Attention 机制
4. Hallucination — 生成看起来合理但实际不存在的内容，是真实风险

**判断框架：** LLM 在系统里的位置 = 理解 + 生成；需要外部补充 = 事实来源 + 权限 + 执行
