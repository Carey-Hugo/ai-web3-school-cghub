## 主线① · RAG 检索增强生成

**一句话理解：**

> RAG = 检索 + 生成。先从外部知识库找到相关片段，再让 LLM 基于这些片段生成答案。

**解决的问题：** LLM 知识过时 / 知识不足 / 幻觉。

**工作流程：**
```
用户问题 → 检索(Retriever) → 合并(Context) → 生成(LLM) → 带溯源的回答
```

**四个关键技术：**
1. **Chunking**：把长文档切成 500-1000 token 的小块
2. **Vector DB**：存向量，搜相似（工具：Pinecone / Milvus / Chroma / FAISS）
3. **Retriever**：根据问题找相关 chunks（向量相似度 / BM25 / 混合）
4. **Rerank**：重排序，从 20 条选最相关的 3-5 条

**RAG vs 上下文窗口：**

| | 直接塞 Context | RAG |
|--|------|------|
| 知识量 | 受 token 限制 | 无限知识库 |
| 时效性 | 依赖模型训练 | 实时更新 |
| 幻觉 | 仍有 | 降低 |

**CGHub 应用：** 公众号文章 → 向量库 → 智能问答；项目文档 → Agent RAG

## 辅线② · Web3 Dev Stack 开发栈

**一句话理解：**

> Web3 Dev Stack = 从想法到链上运行的完整工具链。

**六层全景：**

```
Layer 6 前端：React / Next.js / WalletConnect / wagmi
Layer 5 SDK：viem / ethers.js（调用合约）
Layer 4 合约：Solidity / Foundry / Hardhat（开发+测试）
Layer 3 节点：Alchemy / Infura / QuickNode（RPC）
Layer 2 执行：EVM（以太坊虚拟机）
```
