### 4. 区块链浏览器实战 ✅

**概念学习：**
- 区块链浏览器 = 链上数据查询工具（公开、不可篡改）
- 可查：地址余额、交易记录、合约状态、Token 信息
- 与传统数据库的区别：无须许可，任何人可查

**核心理解：**
- 区块链 = 公开账本，任何人可查但不可随意改
- Etherscan = 访问这个账本的浏览器界面
- 地址 = 银行账户号码（但任何人可查其余额）
- 交易 = 账本上的转账记录

## 💡 今日洞见

1. **Payment/Commerce = 分什么**
   > CGHub 的核心问题不是"做什么工具"，而是"贡献如何被记录、收益如何被分配"。AI Agent 是这个系统的关键基础设施。

2. **Agent 四大能力：Tool Use → Planning → State → Reflection**
   > 从"回答问题"到"执行任务"，AI 需要具备调用工具、规划步骤、管理状态、自我反思的能力。

3. **区块链浏览器 = 链上公开账本的浏览器**
   > 和 Google 搜索的区别：Google 搜的是别人整理好的内容，区块链浏览器查的是原始数据（余额、交易、合约），无人工干预，完全透明。

4. **EOA vs Smart Wallet = 手动挡 vs 自动挡**
   > EOA（外部账户）= 私钥手动签名；Smart Wallet（智能钱包）= 合约自动执行，可以编程多签、角色权限、时间锁。
