### CGHub 技术架构（W2-08 整合）

```
三层架构：
身份层（Lens Profile + 链上声誉）
  ↓
协作层（AI Agent贡献追踪 + Governance规则/争议）
  ↓
价值层（智能合约分配 + x402支付证明）

核心技术组件：
- Cobo Agentic Wallet（AI Agent智能合约钱包）
- x402（AI自主支付证明机制）
- ERC-4337（Smart Account，Agent无私钥）
- Solidity（链上贡献记录，不可篡改）
- Snapshot + 链上投票（治理机制）
```
