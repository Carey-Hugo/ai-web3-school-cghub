```
主线：Payment/Commerce（贡献记录→收益分配）
  ↓
兼固：Governance（规则制定+争议裁决）
  ↓
一体两面构成合伙人协作系统
```

### 三层产品架构（W2-08整合）

```
【身份层】L0-L4 身份体系
  L0游客 → L1创客 → L2贡献者 → L3船票持有者 → L4合伙人

  个人主页 / 作品集 / 项目协作

  链上贡献记录 + 智能合约分配

```
