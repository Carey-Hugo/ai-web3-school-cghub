## 核心知识点

### W3-01 · Chain-aware Context（情境感知上下文）

**区块链三层架构（从外到内）：**

```
AI Agent（决策）
    ↓ 发请求
viem（翻译层，把请求翻译成 ABI 格式）
    ↓ HTTP
Alchemy RPC 节点（区块链前台）
    ↓ 读链
EVM / 链上数据
```

**关键区别：**

```
读链（view 函数）= 不签名，不花 Gas
写链（non-payable）= 签名 + Gas 费用

查余额 → 读链 → 不需要钱包签名
转 ETH  → 写链 → 需要钱包签名
```

**实际验证结果：**

```

ETH 余额: 0 ETH
Block Number: 10958623
Gas Price: 0.0000000119 ETH
```

### W3-02 · Web3 Tool Use（RPC 调用）

**RPC 节点 = 区块链前台**

```
你不能直接闯进区块链数据库
需要通过前台（RPC 节点）帮你查
Alchemy / Infura / QuickNode 是主流 RPC 服务商
```

**viem = 翻译工具**

```
链上数据是二进制格式，人类看不懂
viem 做两件事：
1. 把请求翻译成链能懂的格式（ABI 编码）
2. 把返回的二进制翻译成人能看的数据
```

**ABI = 合约接口说明书**

```javascript
const ERC20_ABI = [
  {
    name: 'balanceOf',           // 函数名
    type: 'function',            // 类型
    inputs: [{ name: 'account', type: 'address' }],  // 参数
    outputs: [{ name: '', type: 'uint256' }],          // 返回值
    stateMutability: 'view'      // 只读，不签名
  }
];

// 调用方式
const balance = await publicClient.readContract({
  address: '0xfff9976782d46cc05630d1f6ebab18b2324d6b14', // 合约地址
  abi: ERC20_ABI,
  functionName: 'balanceOf',
  args: ['0xd8dA6BF26964aF9D7eEd9e03E53415D37aA96045'],  // 查询地址
});
```

**ERC-20 真实合约调用结果：**

```

查询: Vitalik 地址
结果: 0.05448689 WETH + 58.079 ETH
```
