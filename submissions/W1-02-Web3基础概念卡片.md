## 核心概念（边操作边理解）

### 1. EOA vs 合约账户（EOA vs Contract Account）

**定义：**
- **EOA（Externally Owned Account）**：由私钥控制的账户，普通人用的 MetaMask 钱包就是 EOA，可以发起交易（Transaction）
- **合约账户（Contract Account）**：部署在链上的代码，由代码逻辑驱动，不能主动发起交易，只能被动响应调用

**实操看到：**
- 这个合约地址 `0x1dC966...` 没有私钥，是合约账户
- 它有一个 Creation Transaction（创建交易），点进去能看到原始交易从哪个 EOA 发起 → 那就是部署者

**一句话记住：** EOA = 有人控制的钱包，合约 = 有人写了代码的程序

---

### 2. 智能合约（Smart Contract）

**定义：**
一段部署在区块链上的代码，地址是它的"身份"，代码决定了它的行为，不可篡改，自动执行。

**实操看到：**
- Etherscan 显示 "Contract" tab → 里面有 Read（读取）和 Write（写入）按钮
- Read = 读链上数据（免费，不需要签名）
- Write = 触发链上状态变化（要签名付费）
- ABI（Application Binary Interface）= 合约暴露给外部的函数清单，类似 API 接口文档

**一句话记住：** 合约 = 区块链上永远运行的程序，谁都可以调用它的函数

---

### 3. Transaction（交易）vs Call（调用）

**区别：**
- **Transaction（交易）**：写链上状态，需要签名，消耗 Gas，最终上链不可逆（除非合约写了退款逻辑）
- **Call（调用）**：读链上数据，不签名，不消耗 Gas，不上链，只返回结果

**实操看到：**
- Etherscan 的 Read 按钮 = Call（本地执行，看结果）
- Write 按钮 = Transaction（签名广播，等待上链）

**一句话记住：** 想改变链上状态 → Transaction（付费）；只是查看 → Call（免费）

---

### 4. Gas（燃料费）

**定义：**
执行合约代码需要消耗计算资源，Gas 是计量单位，最终用 ETH 支付。

- **Gas Limit**：这笔交易最多烧多少 Gas
- **Gas Used**：实际用了多少
- **Gas Price**：每个单位 Gas 的价格（动态，随网络拥堵变化）

**实操看到：**
- 每一笔交易记录都显示 Gas Used/Gas Limit
- 如果合约逻辑复杂（循环、存储），Gas 消耗就高

**一句话记住：** Gas = 区块链的"运费"，代码越复杂运费越贵

---

### 5. ABI（Application Binary Interface）

**定义：**
合约的函数签名清单，告诉外部"这个合约有什么函数、参数是什么、返回什么"。外部程序（前端/后端）通过 ABI 调用合约。

**实操看到：**
- Contract tab → "Read Contract" / "Write Contract" 下拉列表就是 ABI 暴露的函数
- 每个函数有：函数名、输入参数类型、输出类型、是否可写

**一句话记住：** ABI = 合约的使用说明书，让外部程序能正确调用它

---

### 6. 交易哈希（Transaction Hash / Tx Hash）

**定义：**
每笔交易上链后产生的唯一哈希，像身份证号，可以凭此查询交易状态。

格式：`0x` 开头，64位十六进制字符串

**实操看到：**
- 任何一笔交易右侧都有 Tx Hash，点击进入详情
- 可以看到：From（发送方）、To（接收方）、Value（金额）、Status（成功/失败）、Gas 使用

**一句话记住：** Tx Hash = 链上交易的"身份证号"，可查询，可追溯

---

### 7. 区块（Block）与确认数（Confirmations）

**定义：**
- 交易被打包进区块，区块一个接一个链接成链
- 确认数 = 该区块之后又产生了多少个新区块（越多越安全，越难被逆转）

**实操看到：**
- 每个合约Creation Transaction 显示 Block Number + 后续的 Confirmations 数量
- 新交易通常等 12 个确认（约2-3分钟）才算稳妥

**一句话记住：** 确认数越多，交易越不可逆

---

### 8. 合约创建者 vs 部署者

**实操看到：**
- 进入合约的 Creation Transaction，能看到 "From" 地址 = 部署者 EOA
- 这个部署者的地址，就是当初用 MetaMask 签名发起部署交易的账户

**一句话记住：** 合约地址的 Creation Tx 的 From = 合约的"生父母"
