## 进阶：高质量内容笔记（选3条）

### 笔记 1：Agent 的 Tool Use 能力边界
- **来源：** Harrison Chase / LangChain
- **讨论的问题：** Agent 如何选择使用哪个工具？多工具协作时如何避免循环调用？
- **技术趋势：** Tool Use 正从"硬编码函数列表"向"动态工具发现"演进
- **与 Week 1 的关系：** W2 的核心就是 Tool Use，理解这个演进方向有助于规划 CGHub 的技术选型
- **还不理解的问题：** 如何判断 Agent 的工具选择是否正确？是否有评估框架？

### 笔记 2：x402 支付协议与 AI Agent 的商业化
- **来源：** W2-03 任务描述 / AIxWeb3 School
- **讨论的问题：** AI Agent 如何在没有中心化支付网关的情况下接收链上支付？
- **技术趋势：** x402 是基于 HTTP 的链上支付协议，利用 ETH/UBS 稳定币实现机器对机器支付
- **与 Week 1 的关系：** 从"学习概念"升级到"商业闭环"，这是 AI×Web3 真正落地的关键
- **还不理解的问题：** x402 的具体实现栈是什么？gas 如何处理？

### 笔记 3：Session Key 与 Agent Wallet 的权限设计
- **来源：** 0xSwen / ETHPanda
- **讨论的问题：** AI Agent 发起链上操作时，权限边界如何设计？如何防止 Agent 被滥用？
- **技术趋势：** ERC-7715（Delegate Manager）允许 EOAuthorization 级别的权限委托，Session Key 是具体实现形式
- **与 Week 1 的关系：** Etherscan 实操理解了 EOA vs 合约的区别，这个知识点是理解 Session Key 的基础
- **还不理解的问题：** Session Key 的有效期如何设定？过期后如何续期？
