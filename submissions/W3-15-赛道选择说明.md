## 📌 赛道选择说明

**我们选 Cobo 赛道，核心原因有三：**

### 1. 产品契合度最高
Cobo Agentic Wallet 的 **Pact 协议**正是我们要的"Agent 任务级授权"机制，Agentic Economy 方向跟 CGHub"AI Agent 自动分账"的定位完全一致。

### 2. 技术互补性强
我们项目是"贡献记录 + 链上分账"，Cobo 提供的是"Agent 钱包 + 资金管控"，**两者拼起来才完整**。我们不会重复造钱包，直接用 Cobo 的 Agentic Wallet 做资金侧，专注做业务侧（贡献模型 + 分配规则 + Agent 决策）。

### 3. Sponsor 资源可用
Cobo 提供了 SDK / API 给参赛团队，**CAW 团队可直接对接，凭据走 `caw` CLI 一行 onboarding**（1 分钟完成），大幅缩短我们的工程时间。
